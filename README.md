## Featured projects

### DataDrift: Serverless ETL pipeline

[View project](./Cloud_Engineering/data-drift-etl-aws/)

An AWS-based data pipeline that extracts product data, stores raw records in Amazon S3, transforms them with AWS Lambda, and makes processed data available for SQL analysis with Amazon Athena.

Key areas:

- Event-driven and scheduled data processing
- Raw and processed data zones in Amazon S3
- Serverless transformation with AWS Lambda
- Schema discovery with AWS Glue
- SQL analytics with Amazon Athena

### Resume PH Job Matcher

[View project](./Cloud_Engineering/resume_analyzer_monitoring/)

A Flask application that analyzes resumes, extracts skills and experience, and finds Philippines-based job opportunities that match a candidate's profile.

Key areas:

- PDF resume parsing and skill extraction
- Target-role and experience-level detection
- Job discovery through configurable providers
- Prometheus monitoring and Docker support
- Optional AI-assisted search queries and match explanations
